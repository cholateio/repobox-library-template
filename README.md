# RepoBox 收藏庫範本

**繁體中文** | [English](#english)

這是 [RepoBox](https://github.com/cholateio/repobox) 的收藏庫範本。

按 **Use this template → Create a new repository**，選 **Private** 建一個自己的收藏庫，再照 RepoBox 的安裝步驟設好 Claude token 就能用。第一筆收藏分析完後，這份 README 會換成你的收藏目錄；分類可以在 `taxonomy.yml` 自己改。

## English

This is the library template for [RepoBox](https://github.com/cholateio/repobox).

Click **Use this template → Create a new repository** and choose **Private** to create your own library, then set up the Claude token as described in RepoBox's install steps. Once your first saved repo has been analysed, this README is replaced by your library index; you can edit the categories in `taxonomy.yml`.
